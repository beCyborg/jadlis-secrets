# Доступы агента в одном хранилище 1Password — без Touch ID и без паролей в чате

Скилл `/secrets` для Claude Code держит все логины, токены и ключи агента в одном хранилище
1Password. Агент читает их через сервисный аккаунт, поэтому 1Password не спрашивает Touch ID на
каждую команду. Пароль не попадает в контекст модели: в веб-форму его передаёт одноразовый
локальный адрес, в приложение — «слепой» буфер обмена.

```
claude plugin marketplace add https://gitlab.com/beCyborg/jadlis-hub.git
claude plugin install jadlis-secrets@jadlis
```

## Зачем

- **Одно место для доступов.** Агент не хранит пароли в файлах, `.env`, заметках и памяти. Всё
  лежит в одном хранилище, которое видит только сервисный аккаунт агента.
- **Без Touch ID.** Обёртка `op-agent.sh` берёт токен сервисного аккаунта из связки ключей macOS
  и отдаёт его одной команде `op`. Если токена нет, обёртка переходит на обычный `op` с Touch ID и
  пишет об этом.
- **Пароль не виден модели.** `secret-relay.py` поднимает одноразовый сервер на `127.0.0.1` со
  случайным портом и путём. Агент браузера забирает пароль одним запросом и сразу вписывает его в
  поле. После этого сервер завершается.
- **Алиасы для регистраций.** `proton-alias.sh` создаёт алиасы Proton Pass вида
  `<префикс>-<сервис>`, показывает список и отключает лишние.

## Как поставить

Нужны Claude Code, macOS, 1Password с правом создавать сервисные аккаунты и
[1Password CLI](https://developer.1password.com/docs/cli/). Proton Pass CLI нужен только для
алиасов.

1. Плагин:

   ```
   claude plugin marketplace add https://gitlab.com/beCyborg/jadlis-hub.git
   claude plugin install jadlis-secrets@jadlis
   ```

2. Инструменты: `brew install --cask 1password-cli`, для алиасов ещё `brew install proton-pass-cli`.
3. Скрипты. Скопируй их из папки плагина в `~/.claude/scripts/` (путь к плагину покажет
   `claude plugin list`, или попроси Claude сделать этот шаг):

   ```
   mkdir -p ~/.claude/scripts
   cp <папка плагина>/scripts/* ~/.claude/scripts/
   chmod +x ~/.claude/scripts/op-agent.sh ~/.claude/scripts/secret-relay.py ~/.claude/scripts/proton-alias.sh
   ```

4. Настройки. Скопируй образец и заполни его:

   ```
   mkdir -p ~/.config/jadlis
   cp -n <папка плагина>/agent.conf.example ~/.config/jadlis/agent.conf
   ```

5. Сервисный аккаунт. В 1Password создай отдельное хранилище для агента. Потом на
   my.1password.com → Developer → Service Accounts создай сервисный аккаунт с доступом только к
   этому хранилищу. Токен показывают один раз — скопируй его.
6. Токен в связку ключей. Выполни в терминале и вставь токен, когда команда спросит:

   ```
   security add-generic-password -s op-service-account-agent -a "$USER" -w
   ```

   Имя службы должно совпадать с `OP_SA_KEYCHAIN_SERVICE` в настройках. Не пиши токен в саму
   команду: так он попадёт в историю.
7. Проверка: `~/.claude/scripts/op-agent.sh --check` должен показать `token=found`.

Удалить плагин: `claude plugin uninstall jadlis-secrets@jadlis`. Скрипты и настройки остаются —
удали их вручную.

## Как пользоваться

Пиши обычными словами: «где пароль от X», «сохрани этот токен», «заведи логин для X со
сгенерированным паролем», «какие доступы есть у агента», «смени пароль от X», «сделай алиас для
X». Claude сам вызовет скилл.

- **Логин со сгенерированным паролем.** 1Password сам создаёт пароль из 20 символов. Пароль
  остаётся в хранилище, в форму его передаёт `secret-relay.py`.
- **Токен, который тебе выдали.** Скопируй токен в буфер. Claude перенесёт его в 1Password через
  стандартный ввод, проверит только длину и очистит буфер.
- **Ключ, который сайт показывает один раз.** Агент браузера отправляет его в
  `secret-relay.py receive`, и тот сразу сохраняет ключ в 1Password или в связку ключей.
- **Приложение на Mac.** Агент рабочего стола вставляет пароль через слепой буфер: копирует без
  вывода, вставляет, проверяет длину, очищает буфер. Правило —
  [skills/secrets/references/blind-clipboard.md](skills/secrets/references/blind-clipboard.md).
- **Алиасы.** `proton-alias.sh create <сервис> --dry-run` показывает, что будет создано, и
  ничего не создаёт. Без `--dry-run` создаёт алиас и печатает JSON с полем `alias`.

Самопроверка скриптов без чтения секретов: `zsh tests/selftest.sh`.

## Настройки

Файл `~/.config/jadlis/agent.conf` — строки `KEY="value"`, комментарии через `#`. Каждое значение
бери в двойные кавычки. Этот файл общий для плагинов jadlis-secrets, jadlis-signup, jadlis-mail и
jadlis-browser: каждый читает только свои ключи. Секретов в файле нет.

| Ключ | Что это |
|---|---|
| `OP_VAULT` | хранилище агента в 1Password (имя или id) |
| `OP_ACCOUNT` | аккаунт 1Password, если вошли в несколько |
| `OP_SA_KEYCHAIN_SERVICE` | имя записи в связке ключей с токеном сервисного аккаунта |
| `PASS_LOGIN_ITEM` | запись в `OP_VAULT` с логином Proton для входа в pass-cli |
| `PASS_VAULT` | хранилище Proton Pass для алиасов (по умолчанию `Personal`) |
| `ALIAS_PREFIX`, `ALIAS_DOMAIN` | префикс алиасов и ожидаемый домен |
| `BROWSER_PROFILE` | профиль Chrome для агента браузера (jadlis-browser) |
| `MAIL_ACCOUNT`, `MAIL_FOLDER` | ящик и папка, куда приходят письма подтверждения (jadlis-mail) |
| `SIGNUP_NAME` | имя для форм регистрации (jadlis-signup) |
| `ALLOW_OAUTH` | вход через «Продолжить с Google»: `no` — это делает человек |

Скрипты ищут файл по пути из `JADLIS_AGENT_CONF`, иначе берут `~/.config/jadlis/agent.conf`. Если
файла нет, они пишут понятную ошибку и выходят с кодом 78.

## Границы

- Работает на macOS: токен лежит в связке ключей macOS.
- Сервисный аккаунт видит только своё хранилище и не создаёт новых. Другие хранилища агент
  читает через обычный `op` с Touch ID и только по точной ссылке от человека.
- Создать сервисный аккаунт, положить токен в связку ключей и войти в Proton — шаги человека.
  Токен и пароль Proton не должны проходить через Claude.
- pass-cli не умеет выбирать домен алиаса: он берёт домен по умолчанию из настроек Proton Pass.
  Некоторые сервисы не принимают домены алиасов.
- Некоторые сборки pass-cli не умеют входить без браузера. Тогда скрипт просит один раз выполнить
  `pass-cli login` вручную.
- Оплаты, привязку карт и подтверждение по телефону плагин не делает.
